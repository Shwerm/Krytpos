\doxysubsection{Detailed Description}
Provides a centralized logging system for the Kryptos engine. 

The \doxylink{class_kryptos_engine_1_1_logger}{Logger} class initializes a default logger and provides access to it for consistent logging throughout the engine. Supports both console and file-\/based logging.
