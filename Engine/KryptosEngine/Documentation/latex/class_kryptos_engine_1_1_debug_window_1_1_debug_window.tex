\doxysubsection{Detailed Description}
Provides a graphical interface for debugging game objects in the engine. 

The \doxylink{class_kryptos_engine_1_1_debug_window_1_1_debug_window}{Debug\+Window} displays real-\/time information such as transform and physics values, along with developer-\/defined variables. This tool is essential for debugging during development.
