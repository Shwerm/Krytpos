Detailed Description

Handles the rendering of 2D sprites and texture management.

The SpriteRenderer class simplifies the process of loading, managing, and rendering sprites. It includes support for texture caching to optimize performance.

Loads a texture from a file and sets it for the sprite.

Caches the texture for efficient reuse. Throws an exception if the texture cannot be loaded.

Parameters

If the texture is already cached, it reuses the cached instance. Otherwise, it loads the texture from the specified file and stores it in the cache.
