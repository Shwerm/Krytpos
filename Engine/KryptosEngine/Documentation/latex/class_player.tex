\doxysubsection{Detailed Description}
Represents the player character in the Kryptos game engine. 

The \doxylink{class_player}{Player} class extends \doxylink{class_game_object}{Game\+Object} and includes player-\/specific attributes such as health, movement speed, attack speed, and multipliers for attacks and jumping.
